# AI Workflows

## Listing Generation Workflow

1. User uploads product image
2. Vision AI analyzes image
3. Product attributes extracted
4. Prompt builder generates structured context
5. GPT generates:
   - title
   - descriptions
   - SEO tags
6. Validation layer checks output
7. Results stored in database
8. Export service formats listing

## AI Services
- Product Analysis
- SEO Optimization
