# Design Principles

## Experience Goal

The application should feel like a complete AI operating system for e-commerce launch work.

## UX Principles

- Make the first screen useful, not purely promotional.
- Keep workflows guided, compact, and action-oriented.
- Organize capabilities as studios inside one AI Commerce Workspace.
- Favor clear states: ready, generating, optimized, exported, and unavailable.
- Make marketplace support explicit across Amazon, Shopify, WooCommerce, Etsy, eBay, Daraz, and Generic Stores.
- Use restrained premium visual treatment inspired by modern AI SaaS products: Notion AI, Linear, Vercel, and Canva Magic Studio.

## Interface Language

- Use "AI Workspace" for the authenticated app home.
- Use "Workspace History" for saved generations.
- Use "Product Intelligence" for image analysis outputs.
- Use "Listing Studio", "SEO Studio", "Marketplace Studio", "Creative Studio", and "Marketing Studio" for functional surfaces.

## Scope Guardrails

Brand and UX repositioning must not imply backend behavior that is not implemented. If a capability is future-facing, label it as unavailable or coming through the current workflow rather than presenting it as fully shipped.
